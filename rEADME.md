# FoodHub App

## About
A food ordering application built with Flutter and Firebase.

## Features
- User Login and Registration
- Admin Login
- Food Menu
- Order Management

## Requirements
- Flutter SDK
- Dart SDK
- Android Studio or VS Code

## Installation
1. Open the project folder.
2. Run the following command:

   flutter pub get

3. Connect an Android device or emulator.
4. Run the app:

   flutter run
